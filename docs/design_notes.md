# CAGE-Attention 设计说明

本文档只记录模型与实验的设计思路。

## 1. 动机

现有门控注意力（Gated Attention 风格）的门控只依赖 query 向量，
无法感知当前注意力分布本身是"尖锐"还是"弥散"；Pre-LN 结构下
深层残差范数持续增长，深层往往只做微小增量更新。

## 2. 门控变体

| 变体 | 形式 | 说明 |
|---|---|---|
| `none` | — | 标准注意力，作为对照 |
| `query` | `σ(W_g x)` | 纯 query 依赖门控 |
| `calib` | `σ((W_g x − a·log T − c·H̄)/τ)` | 本工作：按序列长度与归一化注意力熵校准 |
| `null` | 可学习 null KV 槽位 | 稀疏选择基线：null 与真实 token 竞争写入 |

`calib` 的两个校正项分别对应：

- 长度校正 `a·log T`：注意力熵随序列长度近似按 log T 增长，减去该项使门控阈值与长度解耦；
- 集中度校正 `c·H̄`：H̄ 为按 log T 归一化后的逐头注意力熵均值，弥散分布时压低门控。

其中 `a`、`c`、`τ`、集中度缩放 `calib_scale` 均为可学习参数。`calib_scale` 对集中度项额外缩放，提供更灵活的动态范围。

## 3. 归一化方案

- `pre`：Pre-LN，深层增量偏小；
- `post`：Post-LN；
- `mix`：前半 Pre-LN、后半 Post-LN；
- `seednorm`：逐 token 预测缩放并作用于残差流，让深层自行决定写入量。

门控与归一化联合设计，配合可选 LayerScale，观察逐层残差范数与
深层/浅层门控比的变化。

## 4. 任务与度量

合成联想回忆任务：`[k1 v1 ... kn vn, SEP, qi] → vi`，
可精确判定答案是否正确，从而定义"假集中"（max-prob 高但答错）。

度量包括：回忆准确率、门控值与熵/max-prob 的 Pearson 相关、
假集中样本上的门控值、逐层残差范数、深层/浅层门控比、
以及固定训练长度下的多长度泛化曲线。
