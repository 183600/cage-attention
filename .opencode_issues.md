  ValueError from float(), and bool is accepted as 0/1. Validate up front.

  while Python 0.1 yields k=1 (4-ulp snap uses float64 ulp after conversion).

- [ ] standardized_proportion: 2-D input semantics (currently flattened) not
  documented/validated.
- [ ] _bootstrap_seed: out-of-range ints leak torch's incidental overflow
  ValueError instead of the documented bootstrap-seed error.
